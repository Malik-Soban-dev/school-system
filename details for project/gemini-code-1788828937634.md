# Project Roadmap & Execution Phases

## Phase 1: Environment & Base Infrastructure (CURRENT PHASE)
*   **Goal:** Establish a working, error-free deployment pipeline from local Windows to Render, connected to Turso.
*   **Checklist:**
    *   [x] Initialize Laravel project (currently Laravel 13.30.1).
    *   [x] Integrate `turso/libsql-laravel` adapter.
    *   [x] Write and configure the `Dockerfile`.
    *   [x] Resolve the local Composer autoloader/bootstrap failure (Exit code 255).`n    *   [x] Verify local Laravel boot, package discovery, routes, and tests.
    *   [ ] Verify clean database migration on the Render production server.

## Phase 2: Schema, Authentication, & Access Control
*   **Goal:** Secure the application and build the foundational database tables.
*   **Checklist:**
    *   Install Laravel Breeze/Fortify for login scaffolding.
    *   Install Spatie Permission; configure Roles (Admin, Teacher, Student, Parent, Accountant).
    *   Create migrations for `users`, `user_profiles`, `academic_years`, `classes`, and `sections`.
    *   Seed database with Super Admin credentials.

## Phase 3: Core Academic & Student Modules
*   **Goal:** Enable the school to register students and assign teachers to classes.
*   **Checklist:**
    *   Build the Student Information System (SIS) CRUD interface.
    *   Build Subject and Syllabus assignment modules.
    *   Build the Timetable generator and conflict-checking logic.
    *   Build the Attendance module with daily/subject-wise tracking.

## Phase 4: Financial, Grading, & HR Modules
*   **Goal:** Digitize the school's operational workflows.
*   **Checklist:**
    *   **Finance:** Fee structure creation, invoice generation, payment gateway UI.
    *   **Grading:** Exam scheduling, marks entry interface, and PDF report card generation.
    *   **HR:** Staff profiles, leave request portal, and basic payroll generation.

## Phase 5: Communication, Dashboards, & Launch
*   **Goal:** Polish the user experience and finalize for production handoff.
*   **Checklist:**
    *   Build role-specific dashboards (Admin metrics, Teacher class lists, Student grades).
    *   Implement Internal Messaging / Noticeboard system.
    *   Configure automated email/SMS notifications for absences and fee dues.
    *   Perform security audit and Turso query optimization.
