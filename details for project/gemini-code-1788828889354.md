# Product Requirements Document (PRD)
**Project Name:** School-System ERP
**Platform:** Web Application (Laravel 13.30.1, Turso libSQL, Docker, Render)

## 1. Executive Summary
The "School-System" is a cloud-native, scalable Educational Resource Planning (ERP) platform built to digitize, automate, and centralize school management workflows. Designed for high availability on Render using Turso's edge database capabilities, the platform will handle everything from student enrollment and fee collection to grading, HR, and parent-teacher communication.

## 2. Target Audience & User Personas
*   **Super Admin / System Admin:** Full system control, global settings, database backups, and overarching role assignments.
*   **School Administration & HR:** Manages staff profiles, payroll, student admissions, and inventory.
*   **Accountants:** Manages fee structures, generates invoices, tracks payments, and handles expenses.
*   **Teachers / Instructors:** Manages assigned class rosters, inputs daily attendance, records exam grades, and uploads study materials.
*   **Students:** Views timetables, downloads report cards, submits assignments, and checks library book status.
*   **Parents / Guardians:** Tracks child's academic progress, monitors attendance alerts, pays fees online, and views school circulars.

## 3. Core Modules & Functional Requirements
### 3.1 Student Information System (SIS)
*   Complete digital records (demographics, emergency contacts, medical history).
*   Enrollment workflows and class/section promotion logic.
*   Disciplinary/Behavioral tracking logs.

### 3.2 Academic & Timetable Management
*   Subject and syllabus management (compulsory vs. elective subjects).
*   Automated conflict-free timetable generation for teachers and classrooms.
*   Dynamic assignment of substitute teachers.

### 3.3 Attendance Management
*   Daily and subject-wise attendance tracking.
*   Automated SMS/Email alerts to parents for absent/late students.
*   Integration support for future biometric/RFID hardware.

### 3.4 Examination & Grading Module
*   Custom exam scheduling and subject weightage configuration.
*   Dynamic GPA calculations and grading formulas.
*   Automated, downloadable PDF report card generation (via DomPDF or Snappy).

### 3.5 Financial & Fee Management
*   Automated fee invoice generation based on class/scholarship rules.
*   Payment gateway integration (Stripe, PayPal, or local equivalents).
*   Expense tracking, late fee fines, and financial auditing dashboards.

### 3.6 Human Resources (HR) & Payroll
*   Staff onboarding, contract management, and document storage.
*   Leave request workflows (sick, casual, maternity).
*   Automated monthly payslip generation.

## 4. Non-Functional Requirements
*   **Edge Performance:** Database read operations must average < 50ms utilizing Turso's distributed libSQL edge nodes.
*   **Stateless Containerization:** The Render Docker instance must be entirely stateless. All file uploads (assignments, profile pictures) must route to an S3-compatible cloud bucket.
*   **Scalability & Concurrency:** System must support high concurrent traffic during critical windows (e.g., result declaration days, fee payment deadlines).
*   **Security:** Enforce strict RBAC (Role-Based Access Control). Passwords must use Argon2 or Bcrypt hashing.
