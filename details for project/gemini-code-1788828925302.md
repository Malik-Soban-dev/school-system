# System Architecture

## 1. High-Level Architecture
The system employs a modern monolithic MVC (Model-View-Controller) architecture, decoupling the persistent data layer (Turso/libSQL) from the ephemeral application layer (Docker on Render). 

## 2. Core Technology Stack
*   **Backend Framework:** Laravel 13.30.1 (verified locally; confirm `turso/libsql-laravel` compatibility before production deployment).
*   **PHP Runtime:** PHP 8.3-fpm (Production) / PHP 8.3.33 (Local Laragon).
*   **Database:** Turso (Serverless SQLite built on libSQL).
*   **Frontend UI:** Tailwind CSS, Alpine.js (or Livewire), and Laravel Blade components.
*   **Authentication & Authorization:** Laravel Breeze (Auth scaffolding) + Spatie Laravel-Permission (RBAC).
*   **PDF Generation:** `barryvdh/laravel-dompdf` for report cards and fee receipts.
*   **Hosting:** Render Web Service (Docker runtime).

## 3. Database Architecture (Turso/libSQL)
Unlike traditional MySQL/PostgreSQL setups, Turso utilizes the SQLite-compatible libSQL protocol.
*   **Connection:** HTTP/WebSockets via `DB_URL` and `DB_AUTH_TOKEN`.
*   **Data Structure:** Fully relational. Eloquent ORM is used to enforce foreign key constraints, relationships, and cascading deletes logically.
*   **Configuration:** The custom `libsql` driver is registered in `config/database.php`.

## 4. CI/CD & Deployment Pipeline
1.  **Local Development:** Code is authored on Windows/Laragon. Composer platform dependencies are emulated (`platform.php 8.4.0`) to bypass local OS/PHP limitations.
2.  **Version Control:** Code is pushed to GitHub `main`.
3.  **Render Build Phase:** 
    *   Docker fetches `php:8.3-fpm`.
    *   Installs OS-level dependencies (`libzip-dev`, `unzip`, `libpng-dev`).
    *   Injects Composer binary.
    *   Runs `composer install --no-dev --optimize-autoloader`.
    *   Runs asset compilation (`npm run build`).
4.  **Render Boot Phase:** 
    *   Container spins up.
    *   Boot script executes `php artisan migrate --force` to update the Turso schema.
    *   PHP-FPM and Nginx serve the application.
