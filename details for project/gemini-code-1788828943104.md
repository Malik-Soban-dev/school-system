# Design & UI/UX Specifications

## 1. Design System & Frontend Stack
*   **CSS Framework:** Tailwind CSS (Utility-first for rapid UI development).
*   **JavaScript:** Alpine.js for lightweight interactions (modals, dropdowns, tabs) without the overhead of React/Vue.
*   **Icons:** Heroicons or FontAwesome.
*   **Charting:** Chart.js or ApexCharts for dashboard analytics (e.g., revenue graphs, student attendance trends).

## 2. Layout Architecture
*   **Layout Wrapper:** A persistent sidebar navigation layout that collapses on mobile devices.
*   **Top Bar:** Contains Global Search, Notifications (bell icon), and User Profile dropdown.
*   **Mobile Responsiveness:** The UI must be fully mobile-first. Teachers must be able to take attendance and parents must be able to view report cards seamlessly on smartphones.

## 3. Database Schema Design (Core ERD Concept)

*   **`users`**: `id`, `name`, `email`, `password`, `role_id`, `is_active`.
*   **`students_profiles`**: `user_id`, `admission_no`, `dob`, `gender`, `blood_group`, `parent_id`.
*   **`staff_profiles`**: `user_id`, `employee_id`, `department`, `designation`, `date_of_joining`.
*   **`classes`**: `id`, `name` (e.g., Grade 10), `numeric_value`.
*   **`sections`**: `id`, `class_id`, `name` (e.g., A, B, C), `class_teacher_id`.
*   **`subjects`**: `id`, `name`, `code`, `type` (Theory/Practical).
*   **`timetables`**: `id`, `section_id`, `subject_id`, `teacher_id`, `day_of_week`, `start_time`, `end_time`.
*   **`attendance`**: `id`, `student_id`, `section_id`, `date`, `status` (Present, Absent, Late, Half-Day).
*   **`fee_invoices`**: `id`, `student_id`, `amount`, `due_date`, `status` (Paid, Unpaid, Partial), `payment_method`.
*   **`exam_grades`**: `id`, `student_id`, `exam_id`, `subject_id`, `marks_obtained`, `max_marks`, `remarks`.

## 4. UI Component Library (Blade Components)
*   `<x-button>`: Standardized buttons with primary, secondary, and danger variants.
*   `<x-data-table>`: Reusable table component with built-in pagination, sorting, and search filters.
*   `<x-modal>`: Reusable Alpine.js powered modal for quick edits (e.g., marking attendance, adding a fee payment).
